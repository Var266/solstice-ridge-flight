Solstice Ridge is a golden-hour flight game over one stubborn island: a high-wing Kestrel K-2, a paved strip between two hills, a ring course over the ridge, and a mail run that makes you watch the fuel gauge. Three missions plus free flight, an honest arcade flight model (throttle and turn discipline, stalls that rise with bank angle, gear and flap drag, fuel burn, hard-landing damage), chase and cockpit cameras, a glass-cockpit HUD with speed and altitude tapes, and procedural engine and wind audio. Built with Three.js, vendored under `game/vendor/`, no build step and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Controls: W/S throttle, arrow keys pitch and bank, A/D rudder, F flaps, G gear, Space brake, C camera, P pause, R restart. Mouse drag steers, wheel works the throttle.
